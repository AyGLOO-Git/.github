# .github

Defaults org-wide para `AyGLOO-Git`.

GitHub usa este repo para servir templates de issue/PR a todos los repos de la org que no tengan los suyos propios.

## Contenido

- `.github/ISSUE_TEMPLATE/task.md` -- template para issues de mas de medio dia (features, mejoras, refactors).

## Notas

- Solo este repo es publico. Su unico contenido son los defaults de comunidad: sin codigo, sin info de clientes ni proyectos.
- Para anadir o modificar templates, edita aqui y aplica a toda la org de una sola vez.
